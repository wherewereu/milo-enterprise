# Milo Enterprise

8 AI agents running on a Mac mini, orchestrated by Milo.

## What's Here

- `skills/` — Agent skill definitions (research, calendar, health tracking, etc.)
- `agents/` — Agent configurations
- `discord-post.py` — Post messages as individual agent bots
- `twitch-poller.py` — Monitor Twitch streams
- `backup.sh` — Backup script for iCloud
- `openclaw-mission-control/` — Web dashboard for monitoring agents

## Setup

1. Copy `.env.example` to `.env` and configure paths
2. Create your `agent-bot-tokens.json` with Discord bot tokens
3. Install [OpenClaw](https://openclaw.ai)
